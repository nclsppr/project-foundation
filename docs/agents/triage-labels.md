# Triage labels

Engineering skills use five canonical triage roles. Each role maps directly to
the same GitHub label in this repository.

| Label in `mattpocock/skills` | Label in GitHub | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue |
| `needs-info` | `needs-info` | The reporter must provide more information |
| `ready-for-agent` | `ready-for-agent` | The issue is specified for an unattended agent |
| `ready-for-human` | `ready-for-human` | A person must implement the issue |
| `wontfix` | `wontfix` | The repository will not address the issue |

When a skill names a triage role, use the GitHub label from the second column.
Edit that column only if the repository changes its label vocabulary.
